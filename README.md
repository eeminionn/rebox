# RE:BOX

Una caja. Dos vidas.

Landing de RE:BOX con guía de armado, ideas de uso y presentación de la marca.

## Sitio web

[Ver RE:BOX](https://eeminionn.github.io/rebox/)

## Desarrollo local

Sitio estático con HTML, CSS y JavaScript. No requiere compilación.

```sh
python3 -m http.server 4173
```

Abre `http://localhost:4173`.

GitHub Pages publica la rama `main` desde la raíz del repositorio. Las tipografías locales incluyen sus licencias en `assets/fonts/`.
