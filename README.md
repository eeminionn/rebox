# RE:BOX

Una caja. Dos vidas.

Landing de RE:BOX con guía de armado, ideas de uso y presentación de la marca.

## Sitio web

[Ver RE:BOX](https://eeminionn.github.io/rebox/)

## Desarrollo local

Sitio estático con HTML, CSS y JavaScript. No requiere compilación.

```sh
python3 -m http.server 4173
```

Abre `http://localhost:4173`.

GitHub Pages publica la rama `main` desde la raíz del repositorio. Las tipografías locales incluyen sus licencias en `assets/fonts/`.

## Languages

English is the default on every page load. The EN / ES selector at the top left changes all page content, accessible labels and interactive text to English or Spanish without resetting the organizer or comparison slider. Translations and the language switch are managed in `languages.js`; the initial HTML is also in English.
